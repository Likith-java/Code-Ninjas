# Representative scenarios

Four deterministic scenarios generated by `scripts/generate_scenarios.py`
with the fixed seed `20260105`. Re-running the script byte-reproduces these
files. IDs are stable across all four files (machines `SPIN-01..03`,
`WEAVE-01..05`, `DYE-01..02`; orders `ORD-001..ORD-012`).

## Base load (shared)

- 12 orders (300–1000m), 3 spinning (50–60 m/hr), 5 weaving (35–45 m/hr),
  2 dyeing (30–34 m/hr) machines with varied eligible-machine combinations.
- Due dates spread 3600–10080 minutes; priority weights 1–5; staggered
  `yarn_ready` times 0–1440 modelling competing lot arrivals.
- Horizon 10080 minutes (7 days) from `start: 2026-01-05T06:00:00`, `now: 0`.
- One small planned-maintenance window (WEAVE-05, 9500–9560).

## Files and differences

| File | Delta vs base |
|---|---|
| `feasible_load.json` | Base as generated. All orders routable; EDF produces a valid 36-operation schedule (some deadlines missed: tardiness is a soft cost). |
| `weaving_breakdown.json` | Adds loom breakdown on WEAVE-03, minutes 1200–2400. Orders and machines otherwise identical. |
| `late_yarn_lot.json` | Delays yarn for LOT-Y2 (`ORD-007`, `ORD-008`) by 1440 minutes. Everything else identical. |
| `infeasible_load.json` | Empties `ORD-012` dyeing eligibility, so no valid schedule exists. Schedulers must report explicit infeasibility naming ORD-012 — never a fabricated schedule. |

## Honesty notes

- Yarn: `yarn_ready` times are staggered release times for competing lots.
  No cumulative yarn inventory is modelled, so the scheduler enforces
  per-order release times only — it does not enforce stock quantities.
- Tardiness: missing a deadline is a soft objective cost. An order is
  infeasible only when a mandatory operation cannot be placed (as with
  ORD-012's missing dyeing route in `infeasible_load.json`).
- No benchmark or improvement claims are attached to these files; the load
  was sized only so the feasible variants fit the horizon while tardiness
  trade-offs remain (see statistics in the test/review report).
